# Отчёт об инциденте: краткая сводка

**Класс документа:** Post-Incident Report  
**Классификация:** Public / обезличенный  
**Статус:** Завершён  
**Версия:** 1.0  
**Дата:** 2026-01-01  

## Резюме для руководства

### Что произошло

В ночь с 03 на 04 января 2026 года злоумышленники получили несанкционированный доступ к корпоративной инфраструктуре через интернет-доступный сервис класса SharePoint, к которому был открыт публичный доступ. Эксплуатация уязвимости в компоненте сервиса позволила атакующим выполнить код на сервере, собрать учётные данные и токены интеграций, а затем переместиться вглубь сети.

Через 12 часов после первоначального доступа злоумышленники начали подготовку к шифрованию данных. Инцидент был обнаружен системой мониторинга аномального поведения веб-процессов.

### Влияние

| Показатель | Значение |
|------------|----------|
| Время до обнаружения (MTTD) | ~12 часов |
| Время до локализации (MTTC) | ~3 часа |
| Число затронутых серверов | 7 |
| Число скомпрометированных учётных записей | 4 |
| Подтверждённая утечка данных | Частичная (внутренние документы) |
| Шифрование данных | Не начато |
| Простой бизнес-сервисов | 6 часов |
| Финансовые потери (предварительно) | Ограниченные, без выкупа |

### Ключевые выводы

- Публичный доступ административного интерфейса — главный фактор риска.
- Устаревший компонент сервиса не был обновлён в течение 24 дней после раскрытия уязвимости.
- Сервисная учётная запись имела избыточные права в домене.
- MFA была отключена для служебного аккаунта интеграции.
- Резервные копии хранились в том же домене, что и продовые системы.

## Техническое резюме

### Тип инцидента

Целевая атака с первоначальным доступом через эксплуатацию уязвимости в интернет-доступном веб-приложении. По основным тактикам соответствует профилю ransomware/extortion с предварительной выгрузкой данных.

### Характер использованных техник

Атакующие действовали по «living-off-the-land»-методике: в основном применяли системные утилиты и легитимные административные протоколы, что осложняло обнаружение через классические сигнатуры.
